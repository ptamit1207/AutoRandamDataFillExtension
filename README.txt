Auto Form Filler (Random Test Data)

Install (Chrome / Edge / Brave):
1. chrome://extensions kholo
2. Developer mode ON karo
3. "Load unpacked" -> is folder ko select karo
4. Kisi bhi form wale page pe jao -> extension icon click karo -> "Fill Form"
   (ya shortcut: Alt+Shift+F; change karne ke liye chrome://extensions/shortcuts)
